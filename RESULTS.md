# RESULTS.md — результати практичної роботи № 7

## Тема

Робота з базою даних, сутностями та пагінацією в NestJS (модуль `gadgets`).

## Індивідуальний варіант

**Сутність `Gadget` (`gadgets`).** Реалізовано CRUD-модуль для роботи з гаджетами з підтримкою DTO створення, оновлення
та параметрів пагінації.

## Мета роботи

Ознайомитися з підключенням бази даних у NestJS через Docker Compose, описом сутностей, валідацією вхідних даних та
реалізацією пагінації запитів.

## Реалізовані вимоги

1. **Модуль `Gadgets`.** Створено `GadgetsModule`, `GadgetsController` та `GadgetsService` для обробки HTTP-запитів і
   бізнес-логіки.
2. **Сутність `Gadget`.** У `src/gadgets/entities/gadget.entity.ts` описано модель даних для збереження в базі даних.
3. **DTO та валідація.**
    - `CreateGadgetDto` — перевірка полів під час створення запису.
    - `UpdateGadgetDto` — часткове оновлення запису.
    - `PaginationQueryDto` — валідація та трансформація параметрів пагінації.
4. **Конфігурація середовища.** Налаштовано `docker-compose.yml` для розгортання бази даних.
5. **HTTP-перевірки.** У файлі `requests.http` підготовлено та виконано набір запитів для тестування створення,
   отримання списку, оновлення, видалення та обробки помилок.

## Запуск і перевірка

```bash
docker compose up -d
npm install
npm run build
npm run start
```

Застосунок було запущено локально, а запити з `requests.http` виконано через HTTP Client (збережені відповіді у
`.idea/httpRequests/`).

| Перевірка                       | Фактичний результат                                                         |
|---------------------------------|-----------------------------------------------------------------------------|
| Валідний `POST /gadgets`        | Отримано `201 Created`, запис успішно створено                              |
| Невалідні дані `POST /gadgets`  | Отримано `400 Bad Request` з описом помилок валідації                       |
| `GET /gadgets` (з пагінацією)   | Отримано `200 OK`, повертається список гаджетів згідно з параметрами запиту |
| Запит неіснуючого запису        | Отримано `404 Not Found`                                                    |
| `PATCH` / `DELETE /gadgets/:id` | Отримано `200 OK`, запис оновлено або видалено                              |

## Висновок

У межах практичної роботи № 7 реалізовано та перевірено NestJS-застосунок із модулем `gadgets`, сутністю `Gadget`,
набором DTO (включно з `PaginationQueryDto`) та конфігурацією `docker-compose.yml`. Усі основні CRUD-операції, валідація
вхідних даних, пагінація та обробка помилок (`400`, `404`) підтверджені виконаними HTTP-запитами.
